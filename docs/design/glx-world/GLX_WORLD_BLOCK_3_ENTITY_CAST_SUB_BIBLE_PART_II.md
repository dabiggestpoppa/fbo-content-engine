# GLX WORLD — BLOCK 3 ENTITY / CAST SUB-BIBLE — PART II
## Interaction Grammar, Ensemble Design, Arc Progression, Scene Rules, Dialogue Ownership, Production Metadata & Freeze Criteria

## Status
Canonical sub-bible, Part II of II.

## Purpose
Part I established who exists and why.

Part II establishes how characters interact, how ensembles are selected, how cast combinations serve story, how dialogue ownership works, how conflict is generated, how first appearances are sequenced, how mystery is preserved, how supporting characters evolve, how characters retire/change status, how multiple entities share a frame, how FBO/Hermes can consume cast metadata, and what must be frozen before leaving Block 3.

> **A strong cast is not a collection of personalities. It is a system of relationships that produces story.**

---

# EC2.1 — INTERACTION GRAMMAR

Every recurring interaction should have a clear reason.

A scene should ideally contain at least one of:
- disagreement,
- translation,
- temptation,
- calibration,
- teaching,
- challenge,
- restraint,
- discovery,
- reflection,
- escalation,
- reconciliation.

If characters are together only because they are recognizable, the scene is weak.

---

# EC2.2 — THE THREE-CONFLICT TEST

Before writing a scene, identify:

## External Conflict
What is happening in the Market / Outer World?

## Internal Conflict
What is happening inside GLX?

## Relational Conflict
What do the characters disagree about?

A strong scene often contains all three.

Example:
External — London Range breaks.  
Internal — Fear rises.  
Relational — CEREBUS says no confirmation while Chibi wants entry.

---

# EC2.3 — ENSEMBLE SIZE RULE

Most short-form scenes should use:

> **2–4 active characters**

Duo = comedy, contrast, teaching.  
Trio = decision dynamics.  
Quartet = tension / Council-lite.  
Full ensemble = major moments only.

---

# EC2.4 — CORE DUOS

- GLX + Chibi — emotion / self-control / comedy
- GLX + CEREBUS — judgment / logic / research
- GLX + Bull — trend alignment / pressure
- GLX + Bear — downside alignment / danger
- Chibi + CEREBUS — emotion vs probability
- Fear + Greed — protection vs expansion
- Ego + Doubt — confidence vs skepticism
- Curiosity + Discipline — exploration vs restraint

These should recur enough to become recognizable.

---

# EC2.5 — CORE TRIOS

- GLX + CEREBUS + Chibi — central decision triangle
- GLX + Bull + Bear — directional uncertainty / chop
- Chibi + Fear + Greed — impulsive decision pressure
- GLX + Curiosity + CEREBUS — research
- GLX + Discipline + CEREBUS — risk/process
- GLX + Rival + CEREBUS — competing interpretation with evidence

---

# EC2.6 — ENSEMBLE FUNCTION

Each ensemble should have a dominant function: explanation, conflict, comedy, mystery, training, testing, emotional escalation, or philosophical debate.

Do not let every cast combination become interchangeable.

---

# EC2.7 — DIALOGUE OWNERSHIP

## GLX Owns
Judgment, plain-language translation, interpretation, lived experience, decision, ambition.

## CEREBUS Owns
Evidence, probability, classification, state, model conflict, data integrity, warnings.

## Chibi Owns
Emotional exaggeration, impulse, panic, celebration, boredom, relatable inner thought.

## Fear Owns
Threat framing.

## Greed Owns
Reward projection.

## Ego Owns
Certainty / identity framing.

## Doubt Owns
Alternative explanation.

## Curiosity Owns
Question generation.

## Discipline Owns
Rule / boundary / process.

No voice collapse.

---

# EC2.8 — TRANSLATION CHAIN

One of the strongest educational formats:

CEREBUS:
technical state.

Chibi:
confused reaction.

GLX:
plain translation.

Example:

CEREBUS:
> “Directional acceptance remains statistically weak.”

Chibi:
> “English.”

GLX:
> “It broke out, but buyers haven't proven they can hold it yet.”

---

# EC2.9 — CONFLICT ENGINE

Recurring conflict should arise from:
- different objectives,
- different horizons,
- different information,
- different risk tolerance,
- different interpretation,
- different emotional state,
- different rules.

Avoid manufactured conflict.

---

# EC2.10 — MULTIPLE SIDES CAN WIN

If one character is always wrong, tension dies.

Fear can be right. Greed can identify real asymmetric opportunity. Ego can preserve confidence. Doubt can expose model failure. Rival can outperform GLX. CEREBUS can miss context. GLX can override CEREBUS correctly.

This keeps the world honest.

---

# EC2.11 — VICTORY DEFINITION

Victory is not always winning the trade.

Possible victories:
- following process,
- updating a belief,
- avoiding bad risk,
- discovering no edge,
- admitting uncertainty,
- repairing a relationship,
- learning from a rival,
- processing a loss,
- leaving the Market alone.

---

# EC2.12 — FIRST-APPEARANCE SEQUENCING

Recommended cognitive-load order:
1. GLX
2. Chibi
3. Bull / Bear
4. CEREBUS
5. Fear / Greed
6. Discipline
7. Ego / Doubt / Curiosity
8. Rookie / Grounded Friend
9. Mentor / Rival / Specialist roles
10. deeper institutional characters
11. Deep entities

This is guidance, not a rigid publication schedule.

---

# EC2.13 — FIRST-APPEARANCE RULE

A first appearance should demonstrate:
- core function,
- visual signature,
- relationship to GLX,
- one memorable behavior.

Do not explain full lore immediately.

---

# EC2.14 — MYSTERY PRESERVATION

Not every recurring character needs complete explanation, especially CEREBUS, Prime Bull/Bear agency, Deep entities, Black Door-linked figures, and Institutional Layer anomalies.

Knowledge can remain partial, contested, misclassified, or unknown.

Mystery should be intentional, not inconsistent.

---

# EC2.15 — REVEAL LADDER

Stage 1 — Effect  
Stage 2 — Trace  
Stage 3 — Partial Form  
Stage 4 — Classification  
Stage 5 — Relationship  
Stage 6 — History  
Stage 7 — Reclassification

Do not jump from shadow to encyclopedia page.

---

# EC2.16 — CHARACTER ARC TYPES

Possible arcs:
- Growth
- Calibration
- Fall
- Recovery
- Independence
- Rivalry
- Mystery
- Corruption

Use arc type intentionally.

---

# EC2.17 — GLX ARC PROTECTION

Supporting cast should deepen GLX without replacing his central question:

> **Can I understand enough of this system to move through it intelligently without pretending I can control it?**

---

# EC2.18 — CEREBUS ARC PROTECTION

CEREBUS never becomes all-powerful, secretly omniscient, emotionally human by default, or a deus ex machina.

Its arc is:

> **increasing perception + increasing awareness of limits**

---

# EC2.19 — CHIBI ARC PROTECTION

Chibi must not become stupid comic relief or the cause of every mistake.

He learns.

Advanced Chibi can still be funny while becoming better regulated.

---

# EC2.20 — FEAR / GREED ARC PROTECTION

Fear and Greed remain useful even in mature GLX.

Ascendant GLX still experiences caution, ambition, uncertainty, and desire.

Maturity changes governance, not existence.

---

# EC2.21 — RIVALRY RULE

A real rival needs:
- independent goal,
- legitimate method,
- wins,
- losses,
- strengths GLX lacks,
- blind spots GLX sees.

A rival must not be a disguised loser unless later choices create that outcome.

---

# EC2.22 — MENTORSHIP RULE

Mentor scenes should teach frameworks rather than secrets.

Preferred:
- “Here is what I watch.”
- “Here's where this failed me.”
- “You're asking the wrong question.”
- “This only works in this environment.”

---

# EC2.23 — ROOKIE DEVELOPMENT

Rookie growth should be visible through changing questions.

Early:
> “Why did price move?”

Later:
> “What changed in liquidity?”

Later:
> “Is this the same regime?”

The questions show growth.

---

# EC2.24 — SUPPORTING CAST WITHOUT GLX

Supporting characters should sometimes interact without GLX.

Examples:
- Risk Warden vs Systems Engineer
- Rookie asking CEREBUS a bad question
- Rival talking to Macro Cartographer

This makes the universe larger than the protagonist.

---

# EC2.25 — KNOWLEDGE BOUNDARIES

Each character needs explicit things they do not know.

Macro Cartographer does not know CEREBUS internals. Engineer does not fully understand discretionary nuance. Rookie does not know advanced structure. GLX does not know every macro relationship. CEREBUS does not understand all human meaning.

Boundaries create dialogue.

---

# EC2.26 — CHARACTER SECRETS

Secrets may involve personal history, research findings, institutional mandate, or unresolved mistakes.

Avoid overusing secret evil agendas.

Sometimes the strongest secret is:

> “I failed at this before and never told GLX.”

---

# EC2.27 — CHARACTER RETIREMENT

Possible long-term statuses:
- ACTIVE
- RECURRING
- LIMITED
- DORMANT
- RETIRED
- ARCHIVED
- UNKNOWN

Characters can leave active canon without dying.

Death should be rare and meaningful.

---

# EC2.28 — REINTRODUCTION

A dormant character can return if a new regime makes their expertise relevant, an unresolved relationship matters, or new information changes previous conclusions.

Return should feel earned.

---

# EC2.29 — ENTITY RECLASSIFICATION

An entity may change knowledge category without changing true ontology.

An unknown Deep signal may be classified as Species and later proven to be Systematic Infrastructure.

If original uncertainty was canonical, this is evolution rather than retcon.

---

# EC2.30 — CANON STATUS TAGS

Use:
- CANON
- PROVISIONAL
- EXPERIMENTAL
- CONTESTED
- DEPRECATED
- RETIRED

---

# EC2.31 — VISUAL HIERARCHY IN GROUP SCENES

Priority usually:
1. emotional focal character
2. active conflict
3. environment
4. secondary cast
5. easter eggs

Do not give every character equal visual weight.

---

# EC2.32 — GLX VISUAL PRIORITY

If a scene centers on GLX's decision, GLX remains focal.

Exceptions:
- Prime archetype reveal
- CEREBUS Core reveal
- major antagonist entrance
- deliberate awe scene

Even then, GLX's reaction anchors scale.

---

# EC2.33 — SCALE RULES

Chibi may break scale for comedy while retaining identity.

Psychological entity scale may increase with influence: Fear at F5 can dwarf Control District; Greed at G5 can make Projection Palace overwhelm the frame.

Bull/Bear scale increases with directional scope: trace → herd → archetype → Prime manifestation.

CEREBUS scales through environmental presence: terminal → room → Lab → Market overlay → Deep Graph.

---

# EC2.34 — COLOR / SILHOUETTE COLLISION RULE

Protect color ownership and silhouette uniqueness.

GLX = pink / black / gold.  
CEREBUS = blue / violet / controlled pink.  
Fear = warning red/white/shadow.  
Greed = gold/emerald.  
Bull/Bear = regional but distinct.

Major characters should not share nearly identical silhouettes.

---

# EC2.35 — AUDIO ENSEMBLE RULE

Audio cues should be sequenced rather than all triggered simultaneously.

Example:
1. distant hoof vibration
2. CEREBUS tri-tone
3. Fear siren
4. Chibi reaction

The scene should be readable sonically.

---

# EC2.36 — CHARACTER ENTRANCE ECONOMY

Save dramatic entrance treatment for first appearances, state escalation, major returns, transformations, and systemic manifestations.

Ordinary scenes should let characters simply exist.

---

# EC2.37 — EVERYDAY CAST LIFE

Quiet scenes matter:
- Chibi sleeping in Control Room
- CEREBUS running archive cleanup
- GLX teaching Rookie
- Risk Warden drinking coffee
- Engineer fixing a terminal
- Curiosity reorganizing Idea Foundry

Ordinary rhythm makes crisis feel larger.

---

# EC2.38 — COMEDY / SERIOUSNESS DISTRIBUTION

Primary comedy engines:
1. Chibi
2. GLX reactions
3. CEREBUS literalism
4. psychological pair conflict
5. Engineer/practical constraint
6. Rookie misunderstandings

Heavy material is best anchored by GLX, CEREBUS, Fear, Ego, Grounded Friend, Mentor, Rival, or Risk Warden.

Sometimes Chibi should become quiet.

---

---

# EC2.40 — EPISODE CAST BUDGET

Short: 2–3 core characters.  
Mid-form: 3–5.  
Long-form: 5–8 active, broader background cast allowed.

---

# EC2.41 — CAST REUSE RULE

Before inventing a new character, ask:

> **Can an existing entity perform this story function naturally?**

If yes, reuse.

Repetition creates attachment.

---

# EC2.42 — NEW CHARACTER TEST

A new recurring character must provide at least two of:
- new worldview,
- new domain knowledge,
- new emotional relationship,
- new conflict type,
- new visual category,
- new audience access,
- new long-term mystery.

Otherwise do not add them.

# EC2.45 — STATEFUL CHARACTER GENERATION

Future FBO agents should receive current character state.

Example:
Fear = F3 Defensive.  
GLX = post-loss / tired.  
CEREBUS = Sentinel State.

Without state, characters reset every episode.

We do not want that.

---

# EC2.46 — CONTINUITY LEDGER

Track:
- current relationships,
- injuries/damage,
- knowledge learned,
- unresolved conflict,
- active promises,
- current role,
- last major appearance,
- visual-state changes.

Scalable storytelling requires continuity.

---

# EC2.47 — CHARACTER MEMORY LAW

Characters remember meaningful events.

GLX remembers betrayal. Rival remembers being underestimated. Chibi remembers pain. CEREBUS stores failure. Fear remembers threat.

The cast does not reset emotionally without reason.

---

# EC2.48 — INFORMATION DISCLOSURE LEVELS

Possible access classes:
- PUBLIC
- OPERATOR
- RESEARCH
- RESTRICTED
- CORE

A Rookie should not casually know Core Key details.

---

# EC2.49 — THREE-TRUTH MODEL

Production must distinguish:

## Canon Truth
What is internally established.

## Character Truth
What GLX/CEREBUS currently believe.

## Audience Truth
What has publicly been revealed.

> **Just because canon exists does not mean the audience knows it yet.**

---

# EC2.50 — RETCON PREVENTION

Before changing an entity, ask:
1. Is canon actually contradicted?
2. Was prior understanding incomplete?
3. Can this be reclassification?
4. Can this be evolution?
5. Does the change violate a non-negotiable?

Prefer evolution/reclassification over retcon.

---

# EC2.51 — ENTITY FREEZE LEVELS

## Soft Freeze
Concept approved, details adjustable.

## Hard Freeze
Core ontology and identity locked.

## Visual Freeze
Model sheet/palette/silhouette locked.

## Voice Freeze
Dialogue rules locked.

## Production Freeze
Machine-readable schema ready for automated use.

---

# EC2.53 — FORBIDDEN CAST FAILURES

Do not allow:
- CEREBUS becoming oracle
- GLX becoming permanently unbeatable
- Chibi becoming stupid
- Fear becoming pure evil
- Greed becoming pure evil
- Bull = good
- Bear = evil
- institution = villain by category
- Rookie = idiot
- mentor = omniscient master
- rival = loser designed to praise GLX
- everyone speaking the same voice
- every entity getting humanoid form
- mystery entities explained too early
- visual clutter erasing silhouette

---

# EC2.54 — MASS-AUDIENCE / EXPERT TEST

For each core cast member:

> **Can a non-trader understand what this character wants?**

And:

> **Does the character still represent something coherent underneath the story?**

Both required.

---

# EC2.55 — FANDOM / EDUCATIONAL TEST

A strong recurring entity should create recognizable reactions, quotes, silhouettes, symbols, relationships, theories, memes, or emotional arcs—but fandom must emerge from story.

A cast member should also teach through behavior.

Fear teaches threat perception. Greed teaches reward distortion. Bull/Bear teach direction. CEREBUS teaches evidence and uncertainty. Rookie teaches progression. Risk Warden teaches survival.

---

# EC2.56 — STORY GENERATION TEST

Given any entity card, a future agent should be able to answer:
- What would this character notice first?
- What would they want?
- What would they fear?
- What would they disagree with GLX about?
- How would they speak?
- What can they not know?
- How might they change the scene?

If not, the character bible is incomplete.

---

# EC2.57 — BLOCK 3 RELATIONAL PHILOSOPHY

Block 3 transforms abstract forces into relationships.

Direction becomes Bull/Bear.
Emotion becomes psychological cast.
Logic becomes CEREBUS.
Judgment remains GLX.
Institutions become incentives and constraints.
Supporting humans become alternate viewpoints.

The point is not to make finance childish.

The point is to make complexity human-readable.
