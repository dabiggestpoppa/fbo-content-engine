# GLX WORLD — CLARITY PLAN

## Status
Canonical operating clarity document.

## Core Realization
GLX WORLD and the MAD Content Farm are not the same product.

- **GLX WORLD** is the premium intellectual property, narrative universe, visual brand, character system, educational mythology, and long-term audience experience.
- **FBO Content Engine / MAD Content Farm** is the production, transformation, distribution, analytics, localization, and scaling infrastructure.

The infrastructure exists to serve the IP.

The IP must never be reshaped downward to fit generic content-farm conventions.

## Prime Directive

> **Creative canon decides what should exist. Production infrastructure decides how efficiently it can be made and shipped.**

Quality, character consistency, originality, narrative coherence, and intellectual substance outrank volume for GLX WORLD.

## Current Creative Priority

The main bottleneck is no longer tooling.

The primary work is now:
1. build the world,
2. develop the cast,
3. establish the mythology,
4. create locations and factions,
5. define narrative arcs,
6. define recurring series,
7. create an episode grammar,
8. develop a deep content reservoir.

Automation comes after the universe has enough canon to automate without creative drift.

## Success Test

Before shipping a GLX piece, ask:

1. Is this recognizably GLX without the username?
2. Does it preserve canon?
3. Is there a reason for the chosen art style/form?
4. Does it offer insight, emotion, story, identity, or utility?
5. Is it original enough to strengthen the IP?
6. Does the piece make the world feel larger?
7. Would we still be proud of it after the trend that inspired it dies?

If the answer is weak, improve the idea before increasing production volume.
