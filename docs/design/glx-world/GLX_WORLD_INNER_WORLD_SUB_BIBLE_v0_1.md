# GLX WORLD — INNER WORLD SUB-BIBLE v0.1

## Status
Foundational sub-bible for Block 2.4.

## Purpose
The Inner World is a coherent psychological civilization with geography, resource flows, institutions, crisis mechanics, recovery logic, behavioral ontology, and mass-audience story potential.

> **Emotion speaks. Memory advises. Discipline protects. Judgment decides.**

---

# IW.1 — INNER WORLD AS CIVILIZATION

The Inner World is not a collection of emotions. It is a living internal civilization where multiple systems compete and cooperate to keep GLX alive, effective, coherent, and aligned.

Fear protects.
Greed expands aspiration.
Ego protects identity.
Doubt challenges assumptions.
Curiosity explores.
Discipline coordinates.
Memory preserves.
Attention selects.
Imagination generates.
CEREBUS assists.

Problems emerge when one subsystem captures too many resources or bypasses the others.

---

# IW.2 — INTERNAL GOVERNANCE

The Inner World has no king.

Major governing systems:
- Operator — Outer GLX's conscious judgment.
- Chibi — emotional/impulse representation.
- Discipline Core — rules and behavioral constraints.
- Memory Vault — stored experience.
- Strategy Room — conditional planning.
- CEREBUS Interface — measured external and behavioral context.

Decision quality emerges from coordination.

# IW.5 — RESOURCE FLOW

Primary resources:
- Attention — what GLX processes.
- Energy — ability to sustain cognition.
- Emotional Capacity — tolerance for discomfort.
- Discipline — ability to follow intended behavior.
- Confidence — ability to act under uncertainty.
- Memory — stored experience.
- Curiosity — drive to investigate.

Different psychological systems bid for or consume these resources.

---

# IW.6 — RESOURCE CAPTURE

Fear captures Attention and Emotional Capacity.
Greed captures future imagination, Attention, and risk appetite.
Ego captures interpretation and Confidence.
Distraction captures Attention and Energy.
Fatigue reduces nearly every system.

Healthy Discipline does not monopolize resources. It allocates them.

---

# IW.7 — DISCIPLINE GOVERNANCE

Possible Discipline departments:
- Risk Wardens,
- Patience Office,
- Rule Registry,
- Exception Gate,
- Behavioral Audit.

Failure modes:
- Core Brownout — fatigue reduces enforcement.
- Override — Chibi/Ego bypasses restrictions.
- Corruption — rule changes after the outcome is known.
- Rule Inflation — too many rules make action impossible.
- Legacy Rule — old rules survive after environment changes.

Mature Discipline should become simpler and more stable.

---

# IW.8 — MEMORY GOVERNANCE

Memory Vault departments:
- Event Archive — what happened.
- Emotion Index — how it felt.
- Lesson Registry — interpreted lesson.
- Procedural Library — practiced actions.
- Identity Records — self-beliefs.

Misalignment creates distorted learning.

CEREBUS may assist with **Memory Reconciliation** by comparing subjective memory, actual data, rules followed, environmental state, and outcome.

# IW.9 — FEAR SYSTEM

Fear is a defensive institution.

Subsystems:
- Threat Tower,
- Shelter Network,
- Risk Sirens,
- Loss Memory Link.

Healthy Fear is specific. Unhealthy Fear becomes global.

Escalation:
F0 Calm → F1 Awareness → F2 Concern → F3 Defensive → F4 Panic → F5 Shutdown/Avoidance.

---

# IW.10 — GREED SYSTEM

Greed is an expansion institution.

Subsystems:
- Projection Palace,
- Leverage Promenade,
- More Engine,
- Opportunity Mirrors.

Healthy Greed can become ambition. Unhealthy Greed converts imagined reward into certainty.

Escalation:
G0 Content → G1 Interested → G2 Excited → G3 Expanding → G4 Overreaching → G5 Risk Blindness.

---

# IW.11 — EGO & DOUBT

Ego protects self-coherence. Healthy Ego preserves confidence after setbacks. Unhealthy Ego defends self-image against evidence.

Ego Tower grows through wins, praise, public identity, and repeated successful predictions. It shrinks through humility, process, and uncertainty acceptance.

Doubt functions as error checking. It is valuable in research, but dangerous when it prevents timely action after a decision framework is already complete.

---

# IW.12 — ATTENTION ECONOMY

Attention behaves like internal currency. Market movement, P&L, Fear, social media, CEREBUS alerts, memory, hunger, audience comments, and new ideas all bid for it.

The Distraction Bazaar sells novelty.

The Dopamine Arcade runs a loop:

Boredom → stimulus seeking → checking → small reward → more checking → impulsive action → outcome → more stimulus seeking.

---

# IW.13 — PATIENCE AS CAPACITY

Patience Gardens represent:

> **the ability to remain inactive until conditions justify action.**

Patience is active restraint.

Possible visual systems:
- observation pools,
- slow clocks,
- a gate that opens only when conditions are met.

---

# IW.14 — HABIT ENGINEERING

Repeated behavior alters infrastructure.

- Strengthening — repeated action widens a path.
- Extinction — unused path becomes overgrown.
- Replacement — new path bypasses an old one.
- Relapse — stress temporarily reopens an old shortcut.

Behavioral change leaves persistent world consequences.
